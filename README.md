# Highlight Keeper

Chrome 擴充功能，讓你在原文劃線、寫心得，並用可拖曳的閱讀工作桌整理想法。筆記預設保存在瀏覽器本機，GitHub 備份與 AI 功能由你自行開啟。

需要 **Chrome 123 以上**，沒有套件安裝或建置步驟。

## 安裝與更新

1. 打開 `chrome://extensions/`，開啟「開發人員模式」。
2. 選「載入未封裝項目」，指定這個專案資料夾。
3. 更新程式後，在擴充功能頁按重新載入，再刷新正在閱讀的文章；側邊欄請關閉重開。

## 閱讀與記錄

- 選取文字，點浮動工具列的劃線圖示。
- **hover 劃線看註解，點擊劃線直接編輯心得與顏色。**
- 點擴充功能圖示，或按 `Ctrl/Cmd+Shift+K`，開啟閱讀工作桌。
- 「新增便條」記錄整篇文章的想法；劃線心得則附在對應原文。
- 「本頁劃線」的文字可跳回原文，旁邊圖釘可釘選或取消釘選；一般劃線不會自動建立常駐卡片。
- 自動註解會把畫面內劃線的心得以浮動卡片呈現，沿用劃線色系，並以連線指向原文。
- 自由便條和釘選卡片可以拖曳、收合；刪除劃線或自由便條後可按「復原」。復原入口保留到下一次刪除或手動關閉。

### 設定

工作桌「更多」提供：

- **閱讀設定**：自動批註／僅 hover、心得字級、釘選面板寬度，會記住偏好。
- **進階設定**：直接開啟側邊欄的設定頁。
- 收合卡片、整理收藏。

按 `Ctrl/Cmd+Shift+Y` 也可開啟側邊欄。五個分頁分工如下：

| 分頁 | 用途 |
| --- | --- |
| 本頁 | 劃線、標籤、單篇匯出與刪除 |
| AI 導讀 | 論述脈絡、閱讀地圖、名詞解釋與重點 |
| 我的筆記 | 集中查看心得與自由便條，編寫沿用工作桌 |
| 收藏 | 搜尋已儲存文章 |
| 設定 | 顯示、色票、AI、備份與同步 |

## AI 導讀

工作桌「AI 整理 → 複製 AI Prompt」，到 ChatGPT／Gemini 貼上並送出，再回到「貼回 AI 回覆」套用。側邊欄「AI 導讀」也可完成同樣流程。

回覆會檢查來源文章，避免套用到錯誤頁面；啟用預覽時可確認或取消。OpenAI／Gemini API 為選用模式，在進階設定填入自己的 API Key。

## 收藏與備份

收藏總覽支援標題、網址、劃線、心得、標籤搜尋，多選標籤採「符合任一」，並提供分頁、批次整理、匯入匯出及重複頁面整理。

「備份與同步」可下載全部筆記、匯入多個 JSON，或設定 GitHub Token、儲存庫、分支與檔案路徑。

- 自動同步預設關閉，開啟後依排程執行，也可按「立即同步」。
- 單側變動自動同步；兩側都改過的頁面保留衝突，讓你選擇版本。
- 遠端備份損壞或大量刪除時，不會直接套用。
- 分類清理只處理程式先前成功建立並記錄的檔案，不刪除同資料夾裡的其他檔案。
- **下載比對完成不等於上傳或雙向同步成功。** 各操作結果會分開顯示。

## 開發與檢查

```sh
node scripts/check.mjs
node scripts/check.mjs --browser
```

第一個命令執行語法、Node 回歸、資源／翻譯／權限一致性和 diff 檢查。第二個額外使用本機 Chrome 執行工作桌、旁註、段落內註解、側邊欄與排版 fixtures；找不到瀏覽器時可設定 `CHROME_BIN`。

瀏覽器 fixtures 使用真實 DOM/CSS 與模擬 extension API。實際擴充功能、網站相容性與 GitHub 連線仍需實機驗收。

| 檔案 | 職責 |
| --- | --- |
| `manifest.json`、`background.js` | 權限、載入、快捷鍵、共用寫入佇列與同步排程 |
| `contentScript.js`、`contentStyles.css` | 原文劃線、來源定位、編輯、Prompt 與回覆套用 |
| `reading-desk*.js` | 工作桌畫面、卡片模型與持久化 |
| `reading-annotations.js`、`reading-margin-layout.js` | 自動註解、留白偵測與段落旁定位 |
| `sidepanel.*`、`sidebar-*.js` | 側邊欄、收藏與設定 |
| `manager.*`、`tag-organizer.js` | 收藏總覽、標籤與匯入匯出 |
| `auto-sync.js`、`share-link.js`、`parsers.js` | 同步、GitHub API、分享與資料解析 |
| `test/`、`work/verification/` | 回歸與瀏覽器檢查 |

資料與權限說明以 [隱私權政策](PRIVACY.md) 為準。功能索引見 [功能總清單](FEATURES.md)。介面原則見 [UX 指引](docs/UX_GUIDELINES.md)，檢查紀錄見 [全專案檢查報告](docs/reviews/2026-11-18-project-audit.md)。
