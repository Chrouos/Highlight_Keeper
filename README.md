# Highlight Keeper

一個以 Manifest V3 建立的 Chrome 擴充功能，可在任何網頁標註文字、挑選顏色，並把標註資訊（包含原始網址、標註內容與位置）安全儲存在瀏覽器的本機空間。重新開啟網頁時，標註會自動復原。



## UI/UX（v1.3 重做）

介面統一為 **Notion 極簡**：白底、1px 淺灰線、6px 圓角，顏色只留給標註色與焦點藍。完整功能盤點見 `FEATURES.md`。

- **點擴充功能圖示**一律開啟閱讀導覽側欄（`Ctrl/Cmd+Shift+Y`）。閱讀內容、複製 Prompt 與貼回回覆都只在這裡。
- **頁面工具面板**（`Ctrl/Cmd+Shift+K`）只放工具：本頁標註、跨頁搜尋、色票、標籤、備份與 AI 設定。
- 側邊面板與筆記總覽沿用同一組設計 token，層級靠字重與灰階而非大小。
- 預設色票改為淺色系：

  | 色碼 | 對白底對比 | 黑字對比 |
  |---|---|---|
  | `#fff5b8` | 1.10 | 15.8 |
  | `#ffe6cc` | 1.20 | 14.5 |
  | `#dff2e0` | 1.17 | 14.8 |
  | `#dfeefc` | 1.18 | 14.7 |
  | `#fce4ee` | 1.20 | 14.5 |
  | `#ece3fa` | 1.24 | 14.0 |

  舊版是 1.9～2.4（螢光色壓過內文）。升級後**色票**與**自動畫重點的分類色**都會自動搬移（都只在整組都還是舊預設時才動，自己調過就不碰）；**既有標註**要在面板 → 設定 → 標註顏色 → 「把舊的深色標註換淺」手動觸發，會掃過所有頁面重上色。

### 閱讀導覽

點擴充功能圖示，就能在文章旁切換四個分頁：

- **脈絡**：用 3～5 個短段落講清楚文章問題、因果、證據與取捨，約 200～400 字；下方的**閱讀地圖**依文章順序列出大綱，**開始導讀**會逐段帶你讀過本頁標註。
- **名詞解釋**與**重點整理**：分開計算；短文約 3～4 段、中篇 5～7 段、長文 8～12 段重點，另選最多 3～5 個必要名詞。名詞用兩三句白話解釋，段落說明其重要性，可點選回到原文。
- **我的筆記**：依頁面自動儲存在本機，不會放進 AI 請求。

名詞和重點每項都能用 `×` 刪除，「刪除這篇文章的筆記」會清掉這篇的全部內容。預覽時按取消會還原到套用前的樣子。

整個擴充功能只有一個 Markdown Prompt，一次取得脈絡、名詞解釋、重點整理、閱讀地圖與標籤。流程是複製 Prompt → 貼到 AI → 把回覆貼回側欄，貼上即自動套用。OpenAI / Gemini API 保留為選用模式。側欄需要 Chrome 116 以上。

回覆以單一 Markdown 程式碼區塊提供，並保留來源文章網址。若是從畫面複製，Markdown 符號被加上反斜線（如 `\=\=`）也能正確解析。開啟 AI 分頁時側欄保留原文章；套用前會檢查來源，避免把另一篇文章的回覆存進來。預覽中的解釋會保存，未定位項目也能閱讀；狀態會區分待確認與已套用。

## 功能特色

- 在任意網頁選取文字後，一鍵加上高亮標註。
- 閱讀側欄依文章篇幅選擇標註數量，涵蓋主要章節，並提供有因果脈絡的解說。
- 個人筆記依頁面自動儲存在本機，且不會送進 AI 請求；支援 Markdown、JSON 與分享資料匯出／匯入。
- 從內建顏色或自訂色碼中挑選標註顏色，色票在工具面板設定抽屜管理，並即時同步到頁面。
- 透過 `chrome.storage.local` 把標註資訊存於本機，無需任何遠端服務，重新開啟網頁會自動復原。
- 選取文字時會浮出快捷按鈕，直接點擊即可套用最近使用的顏色。
- 點擊既有標註即可開啟設定面板，支援改變顏色、刪除標註與新增/編輯註解。
- 頁面工具面板分為 **本頁 / 全部** 兩個分頁，設定抽屜放色票、標籤、備份與 AI 服務：
  - **本頁**：查看本頁標註，點擊定位到原文。
  - **全部**：可輸入關鍵字/標籤並以下拉選單鎖定特定網址，快速瀏覽跨頁筆記。
  - **備份**：分為「本頁」與「全部筆記」，可下載整份備份或將多個 JSON 一次匯入（已存在的頁面會自動跳過）。
- 搜尋結果卡片會顯示頁面標題、網址、時間與刪除按鈕，點擊即可開啟原頁或定位到標註。
- 新增 **「筆記內容總覽」**（`manager.html`）：集中列出全部頁面、支援關鍵字/標題搜尋、一次匯出/匯入多個 JSON，適合長期備份管理。
- 擴充套件圖示改為 `Icon/` 目錄底下的多尺寸 PNG（16/32/48/128/400px），確保 Chrome 各處載入時都能對應到正確尺寸。

> 目前標註只針對靜態文字節點，尚未支援在可編輯欄位（Input / WYSIWYG）內建立標註。

## 自動同步

在筆記總覽的「GitHub 備份」勾選**自動同步**並設定間隔（1～1440 分鐘，預設 15）。每輪逐頁比對本機、GitHub 與上次同步的基準：

- 只有一邊變動：自動下載或上傳。沒有變動時只查一次分支，不下載也不上傳；上傳時只送內容有變的檔案。
- 兩邊都變動：這一頁兩邊都不動，其他頁照常同步。圖示會出現 `!`，側欄會提示，到筆記總覽逐頁或全部選擇要用哪個版本。
- 一次刪除超過 3 頁且超過 20%、或 GitHub 上的檔案無法解析：視為異常，不自動套用。
- 第一次同步時，兩邊內容不同的頁面都算衝突，不會互相覆蓋。

## 專案結構

- `manifest.json`：擴充功能設定（Manifest V3）
- `background.js`：點圖示開啟側欄、轉發鍵盤快捷鍵。
- `sidepanel.html`, `sidepanel.js`, `sidepanel.css`：閱讀導覽側欄，閱讀與 AI 流程的唯一入口。
- `contentScript.js`, `contentStyles.css`：處理頁面標註、工具面板與唯一的 Prompt／回覆套用流程。
- `auto-sync.js`：定時同步與逐頁衝突判斷（`node test/auto-sync.js`）。
- `parsers.js`：AI 回覆與 Markdown 的純解析函式（`node test/run.js`、`node test/reading-guide.js`）。
- `manager.html`, `manager.css`, `manager.js`：筆記內容總覽頁，支援全域搜尋與批次匯出/匯入。
- `Icon/`：存放 16/32/48/128/400px 的多尺寸圖示，`manifest.json` 與頁面浮動按鈕會根據需求載入不同大小。

## 使用說明

1. 在目標網頁選取文字後，點擊浮動 `HL` 按鈕即可標註。
2. **閱讀導覽**：點擴充功能圖示開啟側欄，按「複製 Prompt」貼到 AI，再把回覆貼回側欄。之後可查看脈絡、閱讀地圖、名詞解釋、重點整理和個人筆記，分享與匯出在「分享與工具」。
3. **工具面板**：按 `Ctrl/Cmd+Shift+K` 或側欄的「標註工具面板」開啟。
   - **本頁**：查看本頁所有標註。
   - **搜尋**：輸入關鍵字（會搜尋標題、網址、標註文字、註解與標籤），搭配下拉選單選擇「全部頁面」或特定網址，即時列出結果並可開啟來源。
   - **設定抽屜**：色票、頁面標籤、本頁與全部備份、AI 服務。
4. **筆記內容總覽**：在側欄的「分享與工具」點「管理所有筆記」開啟 `manager.html`，即可：
   - 搜尋所有頁面的標題、網址、標註內文與註解。
   - 一鍵下載全部筆記 JSON。
   - 匯入多個 JSON，遇到已有筆記的頁面可選擇只加新的或覆蓋。
5. 點擊任一標註可再編輯顏色或註解；滑鼠移到搜尋結果或總覽頁的連結可直接開啟原頁。

## 安裝方式

1. 執行 `npm install` 不是必要步驟，本專案不依賴套件管理。
2. 打開 Chrome → `chrome://extensions/`
3. 右上角開啟「開發人員模式」。
4. 點選「載入未封裝項目」，選擇此資料夾。

# 隱私權政策

Highlight Keeper 由使用者自行管理資料，預設不會收集、傳輸或分享任何個人資訊。

## 資料收集與使用
- 儲存內容：使用者自行建立的高亮與筆記（包含網址、標註文字、顏色、標籤、註解）。
- 儲存位置：預設僅存於瀏覽器本機的 `chrome.storage.local`，不會自動上傳伺服器。
- 使用目的：用於顯示與還原標註、搜尋、匯出/匯入。除上述用途外不會另作其他利用。

## 傳輸與分享
- 預設不會將資料傳出裝置，也不會與第三方分享。
- 若使用者手動設定 GitHub Token 與儲存庫並執行「上傳/下載」，或自行開啟「自動同步」，備份檔才會透過 GitHub API 傳輸，僅用於備份／還原，不與其他第三方分享。自動同步預設關閉。


## 選用的 AI 功能
- 預設網頁版流程由使用者按「複製 Prompt」，再自行貼到 ChatGPT 或 Gemini；使用者送出後，頁面內容會由所選服務處理。
- 若使用者選擇直接呼叫 OpenAI/Gemini API，API Key 僅存於本機，僅在使用者要求產生摘要時傳送當前頁面全文與標註給對應 API。

## 權限
- 權限用途請見 `PRIVACY.md`：storage、unlimitedStorage、activeTab、scripting、sidePanel、clipboardRead、alarms，以及內容腳本覆蓋使用者造訪的頁面。

## 資料保留與刪除
- 使用者可隨時在瀏覽器中刪除擴充功能或清除 `chrome.storage.local`，資料即會移除。GitHub 備份由使用者自行管理，可在儲存庫刪除。
