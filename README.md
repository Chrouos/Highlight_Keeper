# Highlight Keeper

一個以 Manifest V3 建立的 Chrome 擴充功能，可在任何網頁標註文字、挑選顏色，並把標註資訊（包含原始網址、標註內容與位置）安全儲存在瀏覽器的本機空間。重新開啟網頁時，標註會自動復原。



## UI/UX（v1.3 重做）

介面統一為 **Notion 極簡**：白底、1px 淺灰線、6px 圓角，顏色只留給標註色與焦點藍。完整功能盤點見 `FEATURES.md`。

- **Popup** 提供 AI Prompt、回覆貼上、頁面分享，以及「開啟閱讀側欄」與「在頁面開啟面板」。
- 色票管理從 Popup 移到 **面板設定抽屜 →「標註顏色」**；清除本頁標記在面板 AI 卡片下方。
- 側邊面板與筆記總覽沿用同一組設計 token，字級 12–14px，層級靠字重與灰階而非大小。
- 預設色票改為淺色系：

  | 色碼 | 對白底對比 | 黑字對比 |
  |---|---|---|
  | `#fff5b8` | 1.10 | 15.8 |
  | `#ffe6cc` | 1.20 | 14.5 |
  | `#dff2e0` | 1.17 | 14.8 |
  | `#dfeefc` | 1.18 | 14.7 |
  | `#fce4ee` | 1.20 | 14.5 |
  | `#ece3fa` | 1.24 | 14.0 |

  舊版是 1.9～2.4（螢光色壓過內文）。升級後**色票**與**自動畫重點的分類色**都會自動搬移（都只在整組都還是舊預設時才動，自己調過就不碰）；**既有標註**要在面板 → 設定 → 標註顏色 → 「把舊的深色標註換淺」手動觸發，會掃過所有頁面重上色。

### 閱讀側欄

從 Popup 按「開啟閱讀側欄」，可在文章旁切換四個分頁：

- **脈絡**：用 1～2 段講清楚文章問題、因果、證據與取捨，約 250～500 字。
- **專有名詞**與**重點標註**：分開計算；短文約 3～4 段、中篇 5～7 段、長文 8～12 段重點，另選最多 3～5 個必要名詞。名詞用兩三句白話解釋，段落說明其重要性，可點選回到原文。
- **我的筆記**：依頁面自動儲存在本機，不會放進 AI 請求。

AI 預設使用免 API Key 的 ChatGPT 網頁版；也可切換 Gemini 網頁版，複製 Prompt、開啟服務後貼回回覆。OpenAI / Gemini API 保留為選用模式。側欄需要 Chrome 116 以上。

回覆以單一 Markdown 程式碼區塊提供，並保留來源文章網址。開啟 AI 分頁時側欄保留原文章；套用前會檢查來源，避免把另一篇文章的回覆存進來。預覽中的解釋會保存，未定位項目也能閱讀；狀態會區分待確認與已套用。

## 功能特色

- 在任意網頁選取文字後，一鍵加上高亮標註。
- 閱讀側欄依文章篇幅選擇標註數量，涵蓋主要章節，並提供有因果脈絡的解說。
- 個人筆記依頁面自動儲存在本機，且不會送進 AI 請求；支援 Markdown、JSON 與分享資料匯出／匯入。
- 從內建顏色或自訂色碼中挑選標註顏色，Popup 色票支援新增/刪除/覆寫並即時同步到頁面面板。
- 透過 `chrome.storage.local` 把標註資訊存於本機，無需任何遠端服務，重新開啟網頁會自動復原。
- 選取文字時會浮出快捷按鈕，直接點擊即可套用最近使用的顏色。
- 點擊既有標註即可開啟設定面板，支援改變顏色、刪除標註與新增/編輯註解。
- 側邊面板改採 **標註 / 存檔 / 搜尋 / AI 筆記** 四分頁：
  - **標註**：查看本頁標註、複製/下載/匯入 JSON、編輯頁面標籤。
  - **存檔**：分為「本頁」與「全部筆記」兩組按鈕，可下載整份備份或將多個 JSON 一次匯入（已存在的頁面會自動跳過）。
  - **搜尋**：可輸入關鍵字/標籤並以下拉選單鎖定特定網址，快速瀏覽跨頁筆記。
  - **AI 筆記**：預設使用 ChatGPT 網頁版；也能選 Gemini 網頁版，或設定 OpenAI / Gemini API Key 使用直接呼叫。
- 搜尋結果卡片會顯示頁面標題、網址、時間與刪除按鈕，點擊即可開啟原頁或定位到標註。
- 新增 **「筆記內容總覽」**（`manager.html`）：集中列出全部頁面、支援關鍵字/標題搜尋、一次匯出/匯入多個 JSON，適合長期備份管理。
- 擴充套件圖示改為 `Icon/` 目錄底下的多尺寸 PNG（16/32/48/128/400px），確保 Chrome 各處載入時都能對應到正確尺寸。

> 目前標註只針對靜態文字節點，尚未支援在可編輯欄位（Input / WYSIWYG）內建立標註。

## 專案結構

- `manifest.json`：擴充功能設定（Manifest V3）
- `popup.html`, `popup.css`, `popup.js`：彈出視窗（設定色票、開啟面板、連到筆記總覽）。
- `contentScript.js`, `contentStyles.css`：處理頁面標註、側邊面板、搜尋、存檔與 AI 筆記。
- `sidepanel.html`, `sidepanel.js`, `sidepanel.css`：Chrome 閱讀側欄與個人筆記。
- `manager.html`, `manager.css`, `manager.js`：筆記內容總覽頁，支援全域搜尋與批次匯出/匯入。
- `Icon/`：存放 16/32/48/128/400px 的多尺寸圖示，`manifest.json` 與頁面浮動按鈕會根據需求載入不同大小。

## 使用說明

1. 在目標網頁選取文字後，點擊浮動 `HL` 按鈕即可標註；若需更換顏色，可先在 Popup 內設定色票。
2. **閱讀側欄**：在 Popup 按「開啟閱讀側欄」，可查看脈絡、專有名詞、重點標註和個人筆記。Chrome 需為 116 以上。
3. **頁面面板**：按下「在頁面開啟面板」後即可於網頁右側看到四個分頁：
   - **標註**：查看本頁所有標註，複製純文字、下載/匯入 JSON，或為頁面新增標籤。
   - **存檔**：
     - 「本頁筆記」：複製當前頁面、下載本頁 JSON、匯入一份 JSON 到本頁。
     - 「全部筆記」：下載全部頁面的備份 JSON，或一次匯入多個 JSON；對已存在標註的頁面會自動跳過以免覆蓋。
   - **搜尋**：輸入關鍵字（會搜尋標題、網址、標註文字、註解與標籤），搭配下拉選單選擇「全部頁面」或特定網址，即時列出結果並可開啟來源。
   - **AI 筆記**：預設選 ChatGPT 網頁版；也能改用 Gemini 網頁版。按下功能後複製 Prompt、開啟 AI 網頁，貼回回覆即可套用。直接呼叫 API 才需要 API Key。
4. **筆記內容總覽**：在 Popup 點「管理所有筆記」開啟 `manager.html`，即可：
   - 搜尋所有頁面的標題、網址、標註內文與註解。
   - 一鍵下載全部筆記 JSON。
   - 匯入多個 JSON（對已有筆記的頁面會自動跳過）。
5. 點擊任一標註可再編輯顏色或註解；滑鼠移到搜尋結果或總覽頁的連結可直接開啟原頁。

## 安裝方式

1. 執行 `npm install` 不是必要步驟，本專案不依賴套件管理。
2. 打開 Chrome → `chrome://extensions/`
3. 右上角開啟「開發人員模式」。
4. 點選「載入未封裝項目」，選擇此資料夾。

# 隱私權政策

Highlight Keeper 由使用者自行管理資料，預設不會收集、傳輸或分享任何個人資訊。

## 資料收集與使用
- 儲存內容：使用者自行建立的高亮與筆記（包含網址、標註文字、顏色、標籤、註解）。
- 儲存位置：預設僅存於瀏覽器本機的 `chrome.storage.local`，不會自動上傳伺服器。
- 使用目的：用於顯示與還原標註、搜尋、匯出/匯入。除上述用途外不會另作其他利用。

## 傳輸與分享
- 預設不會將資料傳出裝置，也不會與第三方分享。
- 若使用者手動設定 GitHub Token 與儲存庫並執行「上傳/下載」，備份檔才會透過 GitHub API 傳輸，僅用於備份／還原，不與其他第三方分享。


## 選用的 AI 功能
- 預設網頁版流程會在使用者操作後複製 Prompt 並開啟 ChatGPT 或 Gemini；使用者貼上並送出後，頁面內容會由所選服務處理。
- 若使用者選擇直接呼叫 OpenAI/Gemini API，API Key 僅存於本機，僅在使用者要求產生摘要時傳送當前頁面全文與標註給對應 API。

## 權限
- 僅請求執行單一用途所需的權限（storage、activeTab、scripting、內容腳本覆蓋使用者造訪的頁面），用於建立與呈現標註，不用於其他目的。

## 資料保留與刪除
- 使用者可隨時在瀏覽器中刪除擴充功能或清除 `chrome.storage.local`，資料即會移除。GitHub 備份由使用者自行管理，可在儲存庫刪除。
