The tools we use shape the way we think. What happens when we design those tools for a new kind of collaborator?

The slide framework built for agents. A presentation can be more than a finished artifact. It can become a shared space for thinking, editing, and discovering a better story.

Start with the idea

Good tools make room for the work. They stay close when you need them and quietly step aside when you don’t.

The best interface keeps the next action clear, without asking you to manage the interface itself.
