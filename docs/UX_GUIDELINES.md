# Highlight Keeper 介面原則

這份文件記錄使用者在實際操作中確認的偏好，供後續介面修改遵循。

## 工作情境

- 閱讀工作桌服務「正在閱讀與畫重點」：原文居中，摘錄可拖曳並排，隨手寫心得。
- 收藏總覽服務後續搜尋與整理：支援多標籤任一符合、分頁、批次分類與標籤合併。
- 一般劃線不自動產生工作桌卡片；只有使用者明確拉出時才加入。已在桌面的項目可直接定位，不得變成無法點選的灰色項目。
- 工作桌直接複製目前文章的 AI Prompt，並提供開啟 AI、貼回與套用回覆的入口，不要求切換側邊欄。
- 筆記分頁彙整工作桌便條與摘錄心得，不再另開一份空白編輯器；既有文章筆記仍保留。
- 頁邊批註的位置以整個文章區域的外緣計算，不能把段落內緣當成可放文字的留白。
- 頁邊批註隨來源段落進入閱讀範圍而浮現，離開後淡出。同時只自動顯示最接近閱讀位置的一則心得，避免多則競爭注意力。
- 只有明確釘選才常駐或寫入工作桌。釘選後以適合長文的寬度閱讀，自動避開其他釘選內容與開啟的工具面板。
- 隨段落浮現的短批註採手寫註記感；虛線只能留在頁邊留白，距離過遠就不畫。長心得改用正常字體與寬面板；常駐釘選內容則用較寬、不透明且字距穩定的閱讀面板，避免長文窄欄、過多換行與文字透疊。窄螢幕保留輕薄底色，確保文字不與原文重疊。
- 「本頁劃線」點句子直接跳原文；釘選是獨立的次要圖示開關，再按一次取消釘選，不可把整列點擊都當成新增卡片。
- 原文劃線懸停時顯示註解，點擊直接開啟編輯框；查看與編輯都不自動新增常駐卡片。
- 多張釘選批註要自動錯開；空間不足時縮成標題列，不能半透明重疊。進出編輯模式也不能讓面板突然跳回重疊的位置。
- 原文區與心得區不能互相擠壓或覆蓋。長內容可捲動，鍵盤焦點框留在欄位內。
- 同一段劃線的心得只有一份。工作桌卡片與劃線編輯器共用，不能讓人以為需要複製或另存。

## 名稱

- 劃線：原文中的 highlight；摘錄：拉到工作桌的同一段內容。
- 心得：附在某段劃線上的想法；自由便條：不綁定某段原文的獨立文字。
- 放到工作桌：切換同一內容的呈現位置，屬次要操作，以圖示為主。
- 收起／展開全部卡片：動作名稱隨狀態變更。避免「收合材料」等抽象詞。
- 收藏總覽、閱讀工作桌、備份與同步：固定使用同一名稱。

## 視覺與排版

- 中性灰白／深灰，少量藍色提示操作；不採用綠色主題。
- 劃線色保留給使用者的重點，不用彩色框線裝飾整個介面。
- 同類操作採用一致的線條向量圖示，避免混用 emoji、文字字形和圖示。
- 按鈕內文字不拆行。窄畫面時讓整顆按鈕換排；長文章標題和內容可自然換行。
- 次要圖示提供滑鼠提示、無障礙名稱與鍵盤焦點。
- 減少常駐說明、重複入口、大型空白卡片與持續搶眼的刪除操作。

## 操作回饋

- 本頁劃線清單提供逐筆刪除與清除全部，確認時寫明範圍、數量及會連帶移除的心得；保留自由便條、文章筆記與其他頁面。刪除不可透過還原 AI 預覽而回滾其他編輯。
- 清楚區分移出工作桌、關閉工作桌與刪除便條。移出摘錄不刪除原始劃線與心得。
- 自由便條有文字時，刪除前確認；儲存失敗保留輸入並提供重試。
- 自動儲存有可見狀態，不把尚未完成的儲存說成已儲存。
- 全選需寫明範圍，尤其在清單分頁時；刪除與清除收在次要區域。
- 搜尋與標籤篩選優先提供清楚結果；沒有資料與找不到結果使用不同提示。
- 備份可以收合，但在上方保留可直接抵達的入口。

## 檢查範圍

每次修改需檢查繁體中文／英文、窄螢幕、按鈕是否折字、圖示提示、空結果、收合後動作名稱，以及儲存／刪除的實際範圍。涉及行為的變更需測試；單純樣式以瀏覽器排版檢查驗證。

- 劃線互動：hover 顯示完整註解，點擊直接開啟心得編輯器。工具列保留新增便條、本頁劃線；AI 操作集中於 AI 整理，收合與收藏放入更多。

- 工作桌「更多 → 閱讀設定」提供自動批註或僅 hover、心得字級、釘選面板寬度，偏好持久保存。進階設定直接開啟側邊欄設定頁。
- 工作桌刪除劃線與自由便條後，提供當次刪除的復原入口；復原合併資料，不覆蓋較新的工作。復原提示保留至下一次刪除或主動關閉。

- 側邊欄設定採單層展開：備份與同步嵌入時移除收藏總覽的折疊外層與重複標題，不使用卡片套卡片。每個分頁依內容自然高度排列。
- 分頁用語：AI 導讀放 AI 脈絡、名詞、重點；我的筆記集中顯示心得與自由便條，編寫沿用工作桌。

- 側邊欄採閱讀工具的視覺層級：緊湊文章標題、單行操作、搜尋、底線分頁、自然高度清單；避免大型圓角容器套住全部劃線。原文用中等字重，心得用較輕字重與較寬行距。使用系統字體、石墨灰與藍色，深淺色保持相同結構。

- 頁邊批註與釘選面板沿用原文劃線色作為細色條，並保留原文片段作第二個識別線索；不得只靠顏色區分來源。
- 同步失敗不可並列顯示過去的成功結論；網路錯誤與權限錯誤分開，讀取可有限重試，寫入不盲目重送。

- 下載比對、上傳、雙向同步的結果必須標明範圍；下載無差異不可寫成整體已是最新。手動操作結果放在對應按鈕旁，同步結果放在同步控制旁。連線失敗顯示安全的請求步驟，不推斷 VPN、代理或 Token 是確定原因。

- 自動批註必須貼近來源段落：沒有頁邊留白或需要縱向移動超過 80px 時，改排在來源段落下方並預留高度，不能直接讓註解消失。禁止把來源相關批註固定到視窗右下角。

- 文章旁邊的幾何空白不等於可用留白：自動批註須避開網站導覽、目錄、其他可見文字與媒體，以及既有預覽／編輯浮窗。可用時改用鄰近的另一側，否則改排在來源段落下方，不覆蓋網站內容。

- 工具列選單支援 Esc 與點外部關閉；關閉工作桌時也收起選單。心得字級設定須同時作用於短批註、長批註與釘選心得。

- 劃線進入可見範圍即具備自動註解資格，不排除畫面底部的大段區域；跨段或多片段劃線須跟隨當前可見片段，不能固定選第一個 DOM 節點。
