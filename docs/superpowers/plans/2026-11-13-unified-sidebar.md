# 統一側邊欄實作計畫

設計依據：[統一側邊欄規劃](../specs/2026-11-13-unified-sidebar-design.md)。沿用現有 storage keys、資料與保護機制，逐項移轉並在所有功能可用前保留舊入口。

1. 建立本頁、閱讀、筆記及設定的側邊欄導覽；閱讀維持既有各區與 AI 操作，本頁加入標註清單與定位，沒有文章時仍可存取全域功能。驗證切頁、文章切換和筆記保存。
2. 移轉本頁標註編輯、刪除和標籤，以及分享與匯出；新增識別碼導向的訊息處理與失聯標註測試。
3. 移轉顯示、色票和 AI 設定；共用現有設定格式與驗證，測試存檔後跨分頁與重開保持一致。
4. 移轉備份、匯入和 GitHub 同步設定；保留同步三方比對與衝突處理，測試錯誤及恢復。
5. 將快捷鍵與原入口導向側邊欄，核對功能清單後移除多餘面板；更新文件並執行所有測試與瀏覽器視覺檢查。
